**A local-first desktop companion for glucose awareness.**

GlucoDesk is a cross-platform desktop application built with **.NET and Avalonia** to help people keep an eye on CGM glucose data while working on a computer.

It is not just a demo repository. It includes a complete desktop product flow with dashboard, local history, provider integrations, native notifications, privacy controls, diary exports, packaging and public preview releases.

Key areas:

- .NET and Avalonia desktop application
- macOS and Windows support
- macOS DMG packaging
- Windows setup wizard and portable package
- macOS menu bar companion
- Windows system tray companion
- Local-first glucose history and settings
- Secure credential storage through OS-level stores
- Native glucose-awareness notifications
- Privacy mode and anti-spam controls
- Excel and PDF glycemic diary exports
- Local pattern analysis and weekly review
- Italian and English localization
- GitHub Actions release workflow
- Professional documentation, release notes and safety notices

Current public preview:

[**GlucoDesk v0.3.0-preview**](https://github.com/FilippoGaravaglia/GlucoDesk/releases/tag/v0.3.0-preview)

**A local-first .NET CLI for capturing and reusing developer knowledge.**

DevMemory is a command-line tool designed around a simple idea:

> Developers lose technical context too easily.

It helps capture technical decisions, implementation notes, refactoring context, setup steps and project knowledge as structured local memories that can be searched and reused later.

Key areas:

- .NET CLI and global tool
- Local-first developer knowledge base
- Semantic search
- Retrieval-augmented generation workflows
- Qdrant integration
- Ollama and local AI experimentation
- Git-aware memory drafting
- Timeline-based memory exploration
- Graph-oriented memory navigation
- Automated tests and CI
- Structured release and documentation workflow

This project explores how AI-assisted workflows can support real engineering memory, not just code generation.
